# Rock Paper Scissors

Simple Rock–Paper–Scissors game built with HTML, CSS and JavaScript.

How to run

1. Open `index.html` in your browser (double-click or right-click -> Open with).
2. Click Rock, Paper or Scissors to play against the bot.
3. Scores persist in localStorage. Use "Reset Scores" to clear.

Files

- `index.html` — main page
- `css/style.css` — styles
- `js/app.js` — game logic

Possible improvements

- Add images/icons (assets folder) or emoji as fallback
- Add best-of-N mode, animations, and keyboard shortcuts
- Add tests for the game logic
